# Entscheidungen

Architekturentscheidungen zu falzmarke. Eine Datei je Entscheidung, fortlaufend nummeriert,
mit dem Datum und den Folgen. Eine Entscheidung wird nicht überschrieben — sie wird von einer
späteren abgelöst, und beide bleiben lesbar.

**Warum die Nummerierung bei 0029 beginnt.** Die Entscheidungen 0001–0028 sind getroffen, aber
noch nicht als Datei geschrieben; sie stammen aus internen Planungsdokumenten und werden
nachgezogen. Die Lücke ist sichtbar gelassen, statt neu bei 0001 zu zählen: Die Nummern werden
anderswo bereits zitiert, und ein zweites Nummernsystem wäre teurer als eine erkennbare Lücke.

**Was hier steht und was nicht.** Hier stehen Entscheidungen — was gilt und warum. Die
Auftragsdokumente dahinter (Arbeitspakete, Aufwände, Reihenfolgen) liegen privat und nicht in
diesem Repository: Ein Auftrag ist eingefrorene interne Planung, die von außen als Zusage
gelesen wird und die niemand nachpflegt.
